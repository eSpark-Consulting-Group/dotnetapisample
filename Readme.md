# Catalog.API sample
Catalog API sample without authN/authZ
## How to test
### Requriements 
1. Visual Studio 2022
2. Docker
### Steps
1. Clone repo
2. Open cmd/powershell from solution root
3. Run "docker-compose -f docker-compose.yml -f docker-compose.override.yml up -d"
4. Run/debug Catalog.APi project using visual studio
